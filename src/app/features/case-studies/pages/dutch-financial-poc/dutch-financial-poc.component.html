Migrating Camunda 8 Processes at a Leading Dutch Financial Institution

A successful proof of concept demonstrating that TaktX can run enterprise Camunda 8 workflows with minimal code changes — fully integrated with an enterprise OpenID identity provider.

Context

The client is a major Dutch financial institution with a portfolio of business processes already running on Camunda 8. Their engineering teams had invested significantly in BPMN modelling and worker development built around the Zeebe client protocol. The goal of the proof of concept was straightforward: could TaktX replace Camunda 8 without requiring a rewrite of their existing processes or workers — and could it integrate with their enterprise security infrastructure?

What we set out to prove

check_circle
BPMN process compatibility

Existing Camunda 8 BPMN models — designed in Camunda Desktop Modeler — must run on TaktX without any modification to the XML process definitions.

check_circle
Minimal worker code changes

Existing Java workers built on the Zeebe client must migrate to TaktX with only superficial changes — swapping import packages and replacing ActivatedJob with ExternalTaskTriggerDTO. No changes to business logic, variable handling or return types.

check_circle
Enterprise OpenID integration

TaktX must integrate with the institution's existing enterprise identity provider via OpenID Connect — a non-negotiable requirement for any production-grade deployment in a regulated financial environment.

Results

All three goals were met. Existing BPMN process definitions ran on TaktX without any modification. Worker migration required only the expected import swap — no changes to business logic, variable handling, annotations or return types. The enterprise OpenID provider integrated cleanly with TaktX's authentication layer, satisfying the security requirements of a regulated financial environment.

"The migration from Camunda 8 to TaktX required far less effort than anticipated. Our existing BPMN models ran as-is, and the worker changes were limited to swapping a few import statements. The OpenID integration worked within the constraints of our enterprise environment without additional configuration on our side."

— Engineering team, leading Dutch financial institution (name withheld by request)

Technical approach

The proof of concept ran TaktX Engine alongside the institution's existing Kafka infrastructure. Workers were migrated iteratively — one at a time — allowing the team to validate behaviour against known outputs from their Camunda 8 setup. TaktX's Zeebe-compatible protocol meant no changes were needed to tooling, CI pipelines or the BPMN modelling workflow. The Community Console provided real-time visibility into running instances throughout the evaluation.
